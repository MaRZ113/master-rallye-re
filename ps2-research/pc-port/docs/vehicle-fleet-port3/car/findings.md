# Fleet CAR source contracts

All 25 pinned converted CAR assets and protected retail PC car.dx sources passed their existing SHA-256 certificates. None has a duplicate complete ordered XYZ + UV/winding source signature inside its own required chassis set. All 25 therefore retain their existing healthy whole-body source admission, subject to live owner/WORLD/resource validation. Root counts and mixed-material masks remain those of the existing source-generated race registry; this audit does not replace them or use source tags as runtime identities.

`prepare_contracts.py` emits complete source-only index correspondences in `fleet_damage_draft.hpp` and compact eligible-only arrays in `runtime_damage_registry.hpp`. The latter retains all 25 profile metadata entries but null arrays for blocked profiles. Original XYZ, UV, textures and executable bytes are not embedded in these research headers. Original material slots remain ordered in the existing pinned conversion metadata.

## Damage decisions

UFO is completely source-mapped: 1,369 referenced private vertices, with no static exceptions and no wheel resources. It is eligible for the shared damage algorithm only when the current healthy references, complete owner-bound source set, exact material identity and private UV/winding certificate pass. This is a source-ready implementation contract, not runtime qualification of a damaged UFO.

Kia is fully mapped using its independently proven 956 static crew/interior vertices and original mapping policy. Its existing runtime-proven specialized state must remain unchanged. X-Trail remains on its separately proven damage path; this generic audit deliberately does not replace it.

The other 22 profiles have unresolved source vertices; metadata contains exact private indices and mesh paths. Most involve the different original PS2 crew/interior construction. A bounded additional audit compared connected components against the independently verified Kia static roots 17/18/19. It requires full normals/colors/UVs, winding/multiplicity and rigid-relative original geometry at 1e-5 source precision. This recognizes additional shared static components without using names as identity, but does not close any additional full family. Unmatched bodies or unproved crew/interior remain a genuine full-private-damage blocker, not permission to mark all unmapped vertices static.

WOOLDAND/PC Forester is especially close: only private indices 897, 898, 909, 911 remain unresolved in root.0. Their nearest original PC source points differ by approximately 0.0429279 model units. The existing bounded two-proven-neighbor original-triangle correspondence cannot prove these vertices within the established 0.005 authored-revision limit. These diagnostic nearest points are explicitly unauthorized; increasing tolerance would invent a damage alias. PS2 FORESTER is not conflated with WOOLDAND.

Private UV/count ambiguity groups are explicitly recorded. Current material-vector/token equality is necessary but not sufficient: where multiple source candidates remain, require exactly one unchanged original ordered XYZ signature. If ambiguous pieces deform, retain Stock. Every mapped private vertex with multiple native candidates requires agreement of all current-minus-healthy deltas. Cold private trees, unknown epochs, mismatched generations, unresolved mappings and conflicting deltas fail closed before any chassis suppression.

## Reproduction

Run `python prepare_contracts.py`, then `python test_contracts.py` from this directory. Ten focused tests pass. Protected original PC/PS2 inputs stay local; the generator reads the existing pinned local converted assets. No new build root, DLL build, renderer edit, native mutation or gameplay acceptance is performed by this subtask.

Runtime validation remains separate: current chassis owner, complete opaque+alpha cohort, per-pass WORLD/RT/viewport identity, conditional lamp/window preservation, native steering/suspension/spin, Reset and MSAA must pass in the integrated DLL. Full source correspondence alone never proves any of those runtime contracts.

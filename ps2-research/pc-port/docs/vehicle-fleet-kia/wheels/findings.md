# Kia original PS2 wheel: whole-owned-model contract

## GO for bounded integration

The original KIASPORTAGE/WHEEL.PSM and protected PC KiaSportage/wheel.dx were read independently and checked against the accepted fleet source SHA-256 manifest. The strict original terminal-102 reader consumed the original wheel/cylinder trailer; the auxiliary cylinder is not visual geometry. `contract.json` contains original hashes, all four exact native source signatures, ordered position and UV/winding signatures, source material slots, UV ranges, textures and private candidate hash.

The original PS2 and PC local-space bounds match bit-for-bit on all axes, centered exactly on zero:

- X: ±0.14652666449546814
- Y: ±0.3845731019973755
- Z: ±0.39050576090812683

No geometry fitting, scaling, inferred pivot offset or runtime-coordinate modification is required. Earlier exact face partition audit failed because PC and PS2 contain different intermediate face positions, not because their wheel-local extents differ. Whole-owned-wheel replacement does not require individual PC triangles to match individual PS2 triangles. It requires the entire current owned native wheel to be certified and suppressed.

The ignored candidate `KIASPORTAGE-WHEEL-FLEET.ps2model` contains the original four source meshes, 300 vertices, 252 triangles and original private textures. All four source meshes use mode3. Rubber secondary remains its original rubber texture; only independently classified reflective chrome uses the established mixed capture. Original UVs, vertex colors, normals and alpha bytes are preserved. Tread uses original U tiling (wrap U); primary V orientation uses the already confirmed runtime 1−V convention. The converter never copies COMPLETE geometry.

## Required runtime admission

Main integration must join the current certified Kia chassis to the current independent wheel owners. Prior session 11316 is evidence of four independent wheel owners, not a persistent pointer identity. Each owner requires its current four native source records and complete exact source/resource-generation certificate. All four records for that owner must have the same current native wheel WORLD. That WORLD must be retained directly for the private wheel so steering, suspension and spin remain native.

Render all four private source meshes once per current wheel owner, while suppressing all four matching original records. Preflight material support, original textures and reflective capture before suppressing any record. Do not render four complete private wheels for four source records. If any owner record, generation, matrix or material gate fails, leave that entire owned wheel Stock. Never use chassis WORLD, a global draw ordinal, an old pointer, or source record count alone as admission.

Body damage admission is separate. Do not disable native wheel motion or original game damage. Reset must release private GPU resources and invalidate current owner/generation certificates; source CPU data and immutable signatures may persist.

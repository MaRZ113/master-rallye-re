# Smallest safe native material-partition plan

This is a proposal, not a shipped override. Use Xtrail CAR1 first. Existing
Mode4 capture,precision,MSAA,Reset and successful212-entry body registry stay
available as the fallback.

1. Require explicit opt-in,verified game build,current race certificate,rigid
   native world equal to the effective tracked world,known current resource
   generations/revisions and original opaque normal-bearing environment states.
2. Read current CPU-upload mirrors through the existing bounded API. Require
   triangle-list,FVF0x152,stride36,complete VB/IB coverage and legal native
   indices. Recreated/revised resources require revalidation. Never use old
   addresses or F10 ordinals as admission.
3. Compute the same exact unsigned float32 whole-geometry multiset digest.
   It must equal the source PC record digest. Then verify every face key's
   expected multiplicity and assign its proved category. Duplicates are not
   discarded. Conflicting/unknown categories must not receive Mode4.
4. Derive contiguous runs from the **current native index order**,using the
   category map; the source record's two-run Xtrail order is a diagnostic
   expectation rather than an unconditional runtime assumption. Cache by
   device/reset generation,VB/IB identity/generation/revision anddraw range.
   Bound run count and memory; reject rather than synthesize private geometry.
5. Preflight all state and mixed-source prerequisites before suppressing the
   original full-range draw. For each run,retain the original min-index/vertex
   range and use `start_index + 3*first_face` with that run's triangle count.
   Use the original current vertex/index buffers and original world/view.
6. Only a `carshiny` run gets the existing Mode4 texture/COLOROP transaction.
   Its adjacent `carflat`,`carglass` or untargeted run stays Stock in the first
   reflection-only pilot. Restore every changed state before the next run and
   before returning to the game. Neither this stock preservation nor body
   reflection ports PS2 glass/flat/lamp effects.
7. Render each original triangle **exactly once** and preserve native index
   order. No second full-geometry pass,no transparent replay,no delayed draw,
   no wheel/driver/light suppression,no original resource modification.
8. If preflight fails,submit the original full draw once at Stock. If any
   subdraw has already executed,never retry the original full draw: this would
   duplicate geometry. Return the first native subdraw failure; if all succeed,
   return native success. A split submission cannot honestly promise the same
   hypothetical HRESULT as the unexecuted original single DIP. Document this
   narrow replacement policy and test partial draw/state failures.
9. Retain/ref-release original native bindings only through existing lifetime
   rules. Restoration failure blocks subsequent override work and attempts
   repair before another state-dependent draw. Device-loss/trueReset clear the
   partition cache; window-mode reset-echo follows the existing differentiated
   path and never releases live game buffers.

Implemented closeout: invalidation uses the exact current Reset/resource/upload
key and revalidates live admission before cache lookup; cached plans contain no
COM/resource references. A real successful Reset changes the key, failed Reset
suspends the owning reflection pilot, and the window reset-echo keeps its existing
semantics. Unknown/flat/glass runs remain PCStock; this phase does not implement
the optional flat material change.

## Required staged integration change

The current reflection scope surrounds one original native draw. It can change
states for the whole range only,so it cannot implement the partition by itself.
The approved independent overlay needs a bounded draw-execution hook that can
replace that single range with validated contiguous original-IB runs. Baseline
source remains frozen. Main-agent integration must preserve stock paths and
avoid counting the replacement as another full draw/pass. A header-only
request alone cannot safely suppress or replace the original submission.

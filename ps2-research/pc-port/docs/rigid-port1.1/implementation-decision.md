# One original Turkey3 tumbleweed: minimum safe design, not enabled

The observed original reader/clone/backend and physics thread are useful
runtime anchors. They do not supply the private prototype lifetime, original
nonvehicle body admission or destructor/rollback contract. Decision:
**BLOCKED_ON_PRIVATE_RESOURCE_AND_PROP_LIFETIME**; no fake physics fallback.

After those missing links are proved, keep the implementation to one descriptor:
Turkey3:list11/egg13/ai0; original mass5/MOI(2,2,2); original model-local convex
wire and visual mesh. Default disabled; reject unsupported EXE/course/epoch.

1. **Prepare without scene mutation.** Verify source hashes and4612-byte tag101
   grammar with the existing SDK. Native input is4608-byte payload after dispatch.
   Use an owned stream satisfying the actual reader ABI, not a guessed vtable.
   Retain the resulting prototype through a documented native resource owner
   and unique private name. Prove release/clone references and all partial
   allocation rollbacks. Neither byte compatibility nor prototype reuse in the
   stock capture proves this private owner.
2. **Admit at an original physics/load boundary.** Execute only on the observed
   update thread after independently validating current Turkey3 race/scene
   owner and a permitted step boundary. A thread ID alone is insufficient.
   Fresh native Egg and unoccupied private AI, original name registration,
   original nonvehicle body creation43E2A0, installed backend attachment and
   source mass/inertia must be observed/tested. Do not call the original hay
   initializer unchanged: its model/mass/inertia are different. Do not insert
   manager vector entries manually or use D3D EndScene for admission.
3. **Render that body's pose only.** Publish a bounded immutable pose/lifetime
   snapshot from a validated native update. Transform original model-local
   visual vertices once using the native world pose. The staged D3D8 extension
   may draw the private48-face source mesh/texture with scoped state restoration;
   it must not simulate collision or retain stale body pointers. No embedded
   copyrighted assets in code and no original course/renderer modification.
4. **Retire through proven owners.** Invalidate render pose before native
   retirement. Verify clone/prototype/body removal/refcount ordering for normal
   exit, same-course restart, admission failure and shutdown. Already observed
   native cache clearing is a dependency, not complete resource rollback.

Only then test one slow car strike, physical movement/rotation, pose alignment,
restart, exit and failed admission. A visible moving sprite is not acceptance.
No checkpoint barrel, population system, wind simulation or global physics
replacement belongs to this first object.

The next targeted evidence request is **original prop admission and exact
target body/shape release**, gated to that identity so frontend Egg traffic
does not exhaust the cap. Keep native stream/cache proof focused on that
resource. A broader static reverse or another whole-course snapshot is not
the next step. HUD mapping proceeds independently but replacement remains off.

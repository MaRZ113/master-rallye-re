# PAUSE-MENU1 — разведка паузы гонки (retail MRallye.exe, sha bf8aef32…)

Цель: подменю настроек в паузе гонки (SETTINGS ▸), первый пункт — FOV. Изменений в игре нет; только чтение EXE
(Ghidra через REA + objdump) и `Data.sma_unpacked/DataScene/Hud/Hud0.xml`.

## Данные (Hud0.xml)
* `PauseMenuTiles` — `enUITileBox` (рамка, `Width 18`, `Height 5` тайлов), позиция en2d 170,290.
* `PauseMenuChooser` — `gaFrontendPauseMenuAI`: `Enabled*` = `Race/PauseMenu/Enabled`, `StringList*` = `Race/PauseMenu/List`,
  `Value*` = `Race/PauseMenu/Index`, `CurrentText*` = `Race/PauseMenu/Text`, `Tiles` = `PauseMenuTiles`, `Font 1`, `Height 3`.
* Hud0.xml подменяется loose-файлом — высоту рамки под длинный список можно поменять данными.

## Broker (API записи найден)
| Функция | Что делает |
|---|---|
| `0x4d0580` (this=handle, arg=char*) | имя ключа → id (интернирование строки) |
| `0x4d8ec0` | синглтон Broker (`[0x6f9410]`, создаёт при первом вызове) |
| `0x4d8880` (this=Broker, &handle, list*) | создать/заменить значение-**список строк** (расширяет таблицу записей 0x1c байт) |
| `0x4d85f0` (&handle, char*) | записать строку |
| `0x4d8000` (&handle, int) | записать int |
| `0x4d7aa0` (&handle, bool) | записать bool |
| `0x4d6ea0` / `0x4d6760` / `0x4d6520` / `0x4d6650` | прочитать список / int / bool / float |
Список строк — объект 0x10 байт: байт-флаг + вектор указателей на строки (`begin +4`, `end +8`, `cap +0xc`), элемент 4 байта.
Запись в таблице Broker: `{id, payload*, tag}` (тег 0 bool, 2 int — уже читается прокси в `race_epoch.cpp`).

## gaFrontendPauseMenuAI (класс-таблица `0x690310`: имя, ключи List/Index/QuitRace, методы)
| Адрес | Роль |
|---|---|
| `0x454f80` | фабрика: читает имена ключей из XML в `+0x38` Enabled, `+0x28` List, `+0x2c` Index, `+0x30` Text, `+0x3c` Tiles |
| `0x454e00` | init: создаёт список из 2 строк локализации (таблица `0x50`, id 1 и 2 = CONTINUE / QUIT) и пишет его в `Race/PauseMenu/List` |
| `0x455170` | tick: если `Enabled` и меню не открыто → `Show(1)` и `Index = 0`; затем ввод `0x455570` и `0x455c70` |
| `0x455570` | ввод: 4 кнопки по фронту из объекта `[+0x50]`: `+0x1e` вверх → `0x455620`, `+0x1d` вниз → `0x455720`, `+0x1c` выбор → `0x455210`, `+0x1f` назад → `Show(0)` |
| `0x455620` / `0x455720` | `Index ∓ 1` с переходом по кругу **по длине текущего списка**, звук, `Text = List[Index]` (`0x4557b0`) |
| `0x455210` | выбор: `Index == 1` → `Controller/QuitRace = 1`; всегда `Show(0)` и `Controller/Pause = 0` |
| `0x455280` | `Show(bool)`: видимость рамки/стрелки/текста, `Enabled`, при открытии читает и ослабляет громкости (float-ключи) |
| `0x4558e0` | отрисовка: если указатель списка сменился (`[+0x40]`), сбрасывает раскладку — **подмена списка на лету предусмотрена** |
Ключ `Controller/Pause` (0x6b1a3c) и `Race/PauseMenu/Enabled` ставит `gaGameController` (`0x4c3950`).

## Выводы
1. **Запись в Broker решена:** все сеттеры — обычные `thiscall`-функции игры; прокси может звать их из рендер-потока
   (тот же поток, что тикает AI) или писать payload напрямую (int/bool).
2. **Влево/вправо в паузе нет.** Есть только вверх/вниз/выбор/назад. ◀ ▶ — опрос клавиатуры/геймпада самим прокси,
   пока пауза открыта (у прокси уже есть свои клавиши FreeCam/HUD), либо «выбор» листает значение по кругу.
3. **Действия зашиты по индексу:** 0 — продолжить, 1 — выход из гонки, любой другой — тоже «продолжить».
   Своему пункту нужен перехват `0x455210` (выбор), иначе нажатие на SETTINGS закроет паузу, а на индексе 1 — завершит гонку.
4. **Навигация и отрисовка списка любой длины — нативные.** Высота рамки — из Hud0.xml (loose-файл).

## Предлагаемая схема
* Пауза: `CONTINUE · SETTINGS · QUIT` (прокси переставляет QUIT и переводит индекс в перехвате выбора).
* SETTINGS подменяет `Race/PauseMenu/List` на строки настроек с текущим значением, например
  `CAMERA FOV 75`, `HUD ON`, `MOTION BLUR ON`, `GROUND DETAIL FAST`, `FOREST FIX ON`, …, `BACK`.
  Выбор — следующее значение по кругу; ◀ ▶ (опрос прокси) — уменьшить/увеличить; BACK и «назад» — вернуть исходный список.
  После каждого изменения прокси пересобирает строку пункта и ставит `Text`.
* Применение — живое, через уже существующие механизмы (FOV — проекция, эффекты — как F7-обход).
  Сохранение в INI — отдельный шаг (атомарная запись).
* Закрытие паузы любым путём (`Show(0)`) возвращает исходный список.

## Что проверить до реализации
* Набор глифов шрифта Font 1 (есть ли `<`, `>`, `°`, цифры, `:`), иначе подписи без этих символов.
* Перехват `0x455210`: формат детура (как `broker_null_guard`: проверка исходных байтов, откат), работа в Split Screen (Hud1.xml).
* Владение строками списка: кто освобождает старый список при замене (`0x4d8880` → `0x4de1c0`) — чтобы не освободить строки дважды.
* Ширина рамки (`Width 18` тайлов) под самые длинные строки.

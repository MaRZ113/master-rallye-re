# Full reflection admission decision

Recommend integrating all **174 verified source material signatures**, with the
existing strict native opaque two-stage environment, current vehicle owner,
race lifetime, coordinate-policy and resource-generation gates unchanged.
Do not select only the 99 `whitepaint`/`silverpaint` records. Those names provide
a descriptive paint-family breakdown; they are not an executable classifier.

Every accepted record independently joins its actual PS2 source material to
`$shader(carshiny)`, internal mode 3, with effective secondary
`CommonTextures\rendertarget64x64` and no retained-rubber exception. All 174
PC records have the same opaque compiled flags `00000101`. The existing REFL1
mode 3 initialization/handler (`0x3ade58`) and body source-color producer
(`0x322220`) apply; there is no separate chrome-versus-perspex PS2 shader in
these accepted materials. No glass, carglow, transparent, unknown-shader,
conditional named-child or retained-rubber record enters the registry.

The 75 non-paint-name records include genuine body surfaces: Ufo `body-tga` +
`chrome-tga`; Terrano side/bump materials + `perspex-tga`; Xtrail lower-side,
arch and bumper materials + `perspex-tga`. Restricting names to white/silver
paint would omit actual body geometry already proved to use the same PS2
mode 3. Other groups are stickers, lamps, trim or wheel-associated source
regions. Call the aggregate **reflective source material groups**, not 174
painted body panels. Exact anatomical labels remain source/texture leads where
no separate object-owner proof exists.

No additional native color/blend state change is justified solely by the
authored chrome/perspex names. The existing live-state admission must reject
any submission whose native state is transparent, non-environmental, unknown,
or differs from the currently supported opaque contract. A source registry
entry does not override that rejection. Rendering and actual live anatomical
ownership remain bounded by those runtime checks; new-car visual acceptance
is pending user A/B, not supplied by this audit.

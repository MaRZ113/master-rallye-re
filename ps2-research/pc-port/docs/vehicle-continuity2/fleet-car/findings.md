# Fleet CAR source conversion and runtime boundaries

All29 original PS2 vehicle families are accounted for.26 have verified PC counterparts including Forklift; excludingForklift leaves25 selected race families. FORESTER remains a separate unpaired PS2 car; WOOLDAND maps toPCForester. No runtime enablement or native mutation is performed by this source preparation.

## Concrete conversion products

`prepare_contracts.py` verifies original PS2 archive and per-family originalCAR/PC hashes; writes25 ignored lossless CAR-SOURCE.ps2vehicle prototypes (11,658,058bytes total), exact native source certificates, conditional keep-native masks and independent wheel contracts. `convert_runtime.py` converts their full original unconditional body/crew/interior roots to25 ignored CAR-FLEET.ps2model runtime-format candidates (10,093,258bytes total). Existing acceptedXTRAIL-CAR.ps2model and all original resources remain untouched.

Every converted runtime mesh is an original unconditionalPS2CAR root; conditionalbrakeON/glow/windows and independentWHEEL geometry are excluded. All source staticcrew/interior triangles are included once, so the integration must suppress the complete matching native unconditionalbody set, never delete crew by texture name or render extraPS2crew over nativeoccupants. The exact root mapping is whole-owned-chassis→whole-unconditionalPS2CAR; no fabricated one-to-one PCdraw→PS2material mapping is claimed.

PCtag2 alone is insufficient: originalcompiled brakeglow can be a standalone siblingtag2 (X-Trailrecord24). Existing independently source-hash-checked conditional geometry controls exclude these siblings. X-Trail suppression is23 native records and20 originalPS2roots/1980faces, not24records. NativeOFF/ON/window/glow alternatives remain separate unchanged submission boundaries.

## Mandatory live integration gates

The generatedheader includes each native record's fullpositiongeometrydigest, orderedpositiondigest, normalizedUVtopologydigest and strictnativeUV/windingstreamdigest. The expected nativecompiler conversion reverses the firstpair of eachsource triangle. A currentrace/chassis owner andresource/uploadgeneration certificate pluscomplete coherent sourcewarmup is mandatory. Originaldeclaredrootcounts are candidatefacts, never authorization by count. Every suppressednative record must share the currentchassisWORLD; detached/differentWORLD parts require an explicit separate contract orStockfallback.

Damage transfer is NOT granted for these25families fromX-Trail's evidence. Eachfamily needs its own source-backedhealthyreference/deformationmap; until implemented, changed sourcegeometry must use an explicitStockdamagefallback. Nativewheels retain separate steering/suspension/spin transforms; do not attach wheelgeometry to chassisWORLD.24families have originalWHEEL+PCwheel resources with exacthashes/source certificates;UFO has no pairedwheelresource and must not be assigned invented wheels.

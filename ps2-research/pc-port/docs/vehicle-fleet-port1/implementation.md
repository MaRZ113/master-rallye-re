# PS2-VEHICLE-FLEET-PORT1 implementation

A reusable opt-in CAR path loads 24 additional verified families. X-Trail retains its previously user-confirmed chassis, crew, damage, parts and independent wheel path. Full original unconditional CAR geometry includes static crew/interior exactly once. COMPLETE is unchanged.

## Admission and suppression

`RacePS2FleetMode=1` additionally requires `RacePS2ModelMode=1`, the accepted X-Trail base asset, ReflectionMode=4, a supported original executable, a current single-human/one-participant race and the original compiled emitter. Defaults remain Stock. Each family has its own pinned asset and exact original PC source geometry, ordered positions and UV/winding. Source tags/counts alone never authorize rendering.

Before the first suppression, all expected body records must be present in the current owned native list with exact descriptor/resource generations and revisions, single materials and null optional callbacks. Each selected source must appear exactly once in the bounded current render queue under the same instance and material subindex0. Exact packet+5C=0 and +6C=0 plus instance+44 byte-equal to native WORLD establish a shared unchanged transform through original00561A40. VIEW, PROJECTION, viewport and render target distinguish separate render passes. All required material layers are ValidateDevice-tested and restored before drawing color/depth.

Complete source certificates are rehashed only when owner/descriptors/mirror revisions change. Queue/cohort checks run before a private body submission, not once per suppressed source. Later draws check their own current descriptor tokens. Native conditional branches never enter the suppression set. One complete Stock warmup cohort may establish the real native environment matrix. No speculative texture alias, uniform material override or new game-memory writes are used.

The replacement renders original PS2 source materials, with source-specific mode3 mixed framebuffer/environment versus authored secondary textures. Modes0/1/2/3/5/20/21 use the accepted private transaction (mode5/21 two layers). Existing Mode4 capture, 16/32-bit targets, MSAA resolve and Reset remain the common path. Reflection capture failure selects Stock before suppression. Private textures are managed resources, loaded once for the currently selected family. Failed assets are negatively cached; Reset clears resource/certificate state. Pending child transactions participate in shared repair and Reset admission.

## Damage and abnormal failures

The existing X-Trail deformation map is preserved. New families reject private selected native trees or any changed original geometry before committing a replacement; the entire chassis cohort remains Stock. No generic damage map is inferred from tags or similar models. This conservative limitation includes unchanged private clones. Native damage/physics continue normally.

GPU work cannot be undone. An impossible postcommit invariant failure is logged separately, suppresses the already committed body's matching source rather than duplicating it and faults that family to Stock on the next frame. It is never reported as a retroactive whole-frame Stock fallback. Failed DrawPrimitiveUP or restoration HRESULTs are retained and the child is disabled; no retry adds a duplicate body.

## Wheels and lamps

New fleet families retain their independently moving native wheels. Exact original PC/PS2 wheel face multisets match only megane, Navara, NewRav and Xtrail; twenty others differ despite equal triangle totals, and UFO has no paired WHEEL resource. Four-record assumptions are forbidden. Only the accepted X-Trail PS2 wheel path is active.

All25 exact native glow profiles now use the original PS2 RGB-fade texture/state while preserving the game's OFF/ON scheduling and separate native geometry. The20 legacy profiles are byte-identical. Added five are original-source joins with exact PC XYZ+UV runtime hashes, not enlarged position tolerance. Their PS2/PC authored glow geometry differs explicitly. This phase does not claim new fleet-wide OFF-base reflection fixes or measured OFF/ON transitions for every car.

## Evidence and limits

Kia session11316 provides three complete native controls:26 chassis records,30 roots, one chassis WORLD, four independent wheel owners. The new DLL must still pass user rendering acceptance. Source assets and automated fixtures are not gameplay proof. All25 coverage rows distinguish these levels. New family root counts, queue branches or WORLD modes that fail the conservative gates remain Stock and produce bounded diagnostic reasons. Multi-participant races remain Stock for the new path.

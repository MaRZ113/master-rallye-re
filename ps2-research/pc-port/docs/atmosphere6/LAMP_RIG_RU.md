# ATMOSPHERE 6.15 — lamp rig: универсальная расстановка бликов фонарей

## Что было не так (6.6–6.14)
Блики считались в рантайме по каждому lens-draw эвристиками: фиксированный порог `|z| > 1.2 м`,
цвет текселя под центроидом треугольника, «≤2 секции на сторону», а стоп-сигнал — по центру
кластеров glow-карты (`.35 м`, z = lo). Отсюда:
* **выше/ниже** — glow-карта это крупный billboard вокруг фонаря, центр её кластера не совпадает с линзой;
* **много** — тот же фонарь давал tail-секцию, brake-секцию слоя `breaklightson` и кластер glow;
* **не туда** — зеркала/наклейки с «ламповой» текстурой попадали в зону `|z|>1.2` (Pajero, Kangoo, Mattserati);
* **не загораются** — OFF-меш стопа (`$switch(blight)`) не проходит `fleet_owner`, линза не видна рантайму.

## Новый контракт
`tools/atmosphere_lamp_rig.py` решает фонари **офлайн по car.dx** (одинаково для штатных и мод-машин,
ничего не захардкожено под конкретную машину):

| роль | источник |
|---|---|
| brake | OFF-меш группы `$switch(blight)` (любая текстура), связные части, сливаются < 12 см |
| tail | красные лицевые секции линз; если перекрывает brake — складывается в тот же узел (один блик) |
| head | белые/голубоватые секции спереди, на сторону крупнейшая (+ вторая ≥45 % и того же уровня) |
| fog/aux | остальные белые передние секции ≥12 % главной фары, парные (или по центру), не янтарные |
| reverse | белые задние секции (нет — тёмная секция как запасной вариант) |

Фильтры: лицом вдоль оси машины (`|nz| ≥ .45`), в передних/задних 30 % длины, **видимы с торца**
(9 лучей по площади секции, ≥1/3 не перекрыты кузовом далее 8 см — отсекает зеркала, не режет
решётки/кенгурятники), секции не сшиваются через центральную линию, двухслойные линзы сливаются.

Выход: `lamp_rigs.txt` (формат для прокси), `lamp_rigs.json` (полный отчёт), `<car>.png` и `sheet-*.png`
(вид спереди/сзади/сбоку: текстуры линз, зелёный контур = blight OFF, оливковый = glow-карта,
кольца = блики: голубой head, зелёный fog, жёлтый brake (+красное кольцо = tail в том же узле), белый reverse).

## Рантайм (прокси)
* `Atmosphere.ini`: `LampRigs=Atmosphere/vehicles/lamp_rigs.txt` (по умолчанию), `LampRigsEnabled=1`.
* Машина сопоставляется **один раз** по своему lens-draw: текстура + число индексированных вершин +
  границы в пространстве машины (допуск 6 см). Лог: `atmosphere_lamp_rig_match` / `atmosphere_lamp_rig_miss`.
* Дальше каждый кадр выводятся ровно точки рига в матрице этого draw; стоп горит, пока у этой машины
  отрисовывается glow-карта (последние 2 кадра); задний ход — только на R.
* Машины без рига (мод без прогона инструмента, PS2 RaceFleet-замены) — прежний путь 6.14.

## Мод-машина
```
set PYTHONPATH=D:\Game\Master Rallye\master-rallye-re-vehicles\src
python tools\atmosphere_lamp_rig.py OUT --root <папка с машинами> <Машина>
```
Проверить `OUT\<Машина>.png`, дописать блок `car ...` из `OUT\lamp_rigs.txt` в
`Atmosphere\vehicles\lamp_rigs.txt` (или прогнать весь каталог машин целиком).

# План: настройки графики в игре и что осталось по PS2

## 1. Нативный интерфейс настроек

Цель — родные экраны игры (вид как на концепте «Renderer Options»), без Win32-окон. Размещение — MENU_PLAN_RU.md.

| Этап | Что делаем | Нужен реверс | Проверка |
|---|---|---|---|
| M1 Broker-запись | Прокси регистрирует ключ-список строк и int-индекс в Broker, читает их обратно | функции регистрации/записи Broker (сейчас прокси Broker только читает) | лог: ключи видны в race_epoch-снимке |
| M2 Пункт на существующем экране | Один egg `gaFrontendMultistateAI` (например ANISOTROPIC FILTERING) loose-XML в Advanced Options на ключах прокси | — (данные) | пункт листается, значение в Broker меняется |
| M3 Сохранение | Apply → атомарная запись MRRRenderer.ini / PS2Port.ini (temp + MoveFileEx), пометка «после перезапуска» | момент Apply экрана (`gaFEScreenGraphicsOptionsAI`) | INI меняется, игра не падает |
| M4 Новые кнопки | GraphicsMain.xml + RENDERER OPTIONS и PS2 PORT; переход на новые экраны | обработчик кнопок `gaFEScreenGraphicsMainAI`, создание экрана | переход и возврат Back |
| M5 Экраны | RendererOptions.xml (концепт), PS2 Port → 4 подэкрана (Vehicles / Course / HUD / Picture & Sound), подписи в языковом файле | экранный класс для своих экранов (Accept/Back) | все пункты, джойстик/клавиатура |
| M6 Пауза | CAMERA FOV ◀ ▶ и SETTINGS ▸ (подменённый список паузы с живыми пунктами: FOV, HUD, motion blur, GroundDetail, ForestFix, трава, птицы, цвет, TV) | сборка `Race/PauseMenu/List`, ◀ ▶ в `gaFrontendPauseMenuAI` | применение без перезапуска гонки |

Живое применение есть уже сейчас для FOV (проекция) и draw-time эффектов (механизм F7-обхода);
AA, режим окна, частота, флот и отражения — только после перезапуска.

## 3. Производительность (следующие кандидаты)

1. Флот: кэш владельца и сертификата фар/колёс/кузова на кадр (≈2,5 мс при машинах рядом), убрать пики 27–29 мс.
2. PS2 HUD: разбор egg один раз на сущность за кадр (0,33 мс).
3. Вода: поиск курса по строке на каждый draw → кэш на гонку.
4. Префильтр цепочки DIP: ранний выход по caller RVA/FVF до вызова обработчиков.

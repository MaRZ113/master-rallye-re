PS2WaterAtmosphere=1: оба нативных PS2-water слоя получают общий sky/ambient/fog RGB gain на свежих приватных вершинах. Альфа, UV, время/пауза, blend, FIX56 луж, depth и отражённые координаты сохранены. Fog color входит в прежнюю WaterTransaction; если PC-water fallback уже временно изменил fog, используется его исходное значение, чтобы избежать двойного преобразования. Это согласование цвета, не новые отражения/геометрия воды. PS2WaterAtmosphere=0 возвращает прежний вид; параметр LiveTuning.

SplineAtmosphere=1: исходный spline package — opaque texture×vertex prelight; его fresh world batches раньше обходили Resolver. Теперь ambient RGB/fog применяются при том же подтверждённом pre-UI boundary. Alpha/UV/движение/пауза остаются исходными. В формате нет authored normals: используется ambient-only, без выдуманных нормалей или бликов. SplineAtmosphere=0 отключает изменение, LiveTuning. Ни тяжёлой классификации, ни новых RT/draw calls нет; добавлен линейный RGB loop по уже создаваемым вершинам, один gain на submission.

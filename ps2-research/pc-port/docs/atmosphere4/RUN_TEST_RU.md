# Короткая итоговая игровая проверка — выполнить, когда будет возможность

Ничего не установлено в игру автоматически. Новую DLL проверять только после закрытия игры; `Install-Candidate.ps1` создаёт backup и не выбирает INI за владельца. Все необходимые прежние metadata прилагаются, GT3 sky textures не распространяются: сохранить существующий CustomSet. Финальная приёмка остаётся у владельца.

1. Проверить manifest, установить runtime-overlay в тестовую копию. Скопировать `profiles/Control-29.ini` как Atmosphere.ini. Холодный France1/Patrol: F10 + скрин; затем при неизменной камере `SkyFix-Only.ini`, сохранить и дождаться LiveTuning (~30 frames), F10 + скрин. FreeCam: горизонт / взгляд вверх / другая высота. Текстуры те же; проверить оба sky layers и верхний cap.
2. `GT3-Style.ini`: France1/Patrol и Tata, Turkey2 (трава/вода), Turkey3 (фабрика/металл). Один matched camera A/B на каждом проблемном участке; `Control-29.ini` возвращает исходный art 2.9. `Contrast-Only`, `Halo-Only`, `Rim-Only`, `Vignette-Only`, `Lens-Only` отделяют причины. Включение/выключение — сохранением INI при LiveTuning=1, Enabled/CustomSet/catalog структурные изменения требуют нового процесса.
3. Открытое солнце → за скалой/зданием → деревья → открыто; проверить halo/flare не протекают. HUD/карта/пауза читаемы, стекло/лампы/wheels не получают новый rim. Проверить тормозной glow-on, отражения при поворотах камеры, физические объекты, FreeCam и Collision Debug.
4. В том же процессе Restart → F10, меню → re-entry → F10. Затем resize/Alt-Tab/Reset. Без stale color/sky UV, пустых текстур и восстановления ошибочных states. Для нового layout использовать штатную package metadata, без пересборки DLL и новых object SHA.
5. Отдельно PC baseline и PS2-loose France1/Turkey2/Turkey3. Сохранить текущий PS2Port.ini. В sectioned ConfigVersion=3 профиль `PS2Port-Compatibility.ini` включает Reflection=1 (=исторический4), VehicleLighting=1, Water=1. Для PCWater повторить Turkey2 с Water=0. Проверить ориентацию отражений/alpha/анимацию воды. `Classic-AtmosphereOff.ini` возвращает native Atmosphere-off; системный Baseline DLL в build-report — отдельный тестовый вариант.
6. FPS/CPU сравнивать с Trace=0, одинаковыми camera/sky/course/car/положением, после warmup ≥300 кадров. Отдельно короткий F10 Trace=1 для diagnostics; не выдавать его overhead за обычный FPS. Сравнить resolver hit/miss/skip и cache reset; не должно быть повторной дорогой классификации каждый draw. FPS/GPU-time сейчас НЕ измерены.

Откат: собственный installation backup возвращает точную исходную DLL/INI; rollback-029-experimental содержит контроль 2.9, rollback-005 — принятую основу005. Новые metadata не меняют original assets. Если версия005 не использует дополнительные каталоги, их присутствие не означает их загрузку. Не удалять чужие файлы ради отката.

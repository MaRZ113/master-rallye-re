# Independent checks and numerical scope

Fresh canonical PackFS reads reproduce all four source owners/material bytes,
strip ranges, ancestor paths and method-dependent counts. Integration tests read
tag2 and material directly from original PSM offsets, separately from report
aggregation. Canonical ELF tests verify original vtable/return/branch words.
Existing GEOM1 water/nonwater byte probes and source totals remain regression
anchors; full old comparison report SHAs are preserved without rerunning the
three all-surface comparisons.

The complete Turkey boat group is checked a second way: all113 transformed
source triangles are exhaustively compared under six corner permutations with
the125 original decoded PC draw825 triangles. There are113 unique target
records, zero ambiguous face matches and12 remaining target records. Maximum
absolute coordinate residual is0.00039404595099767903. Pair-identity SHA and
short target-index samples are in boat-congruency.json; the full pair list is
ignored. This check does not reuse the shape search's point grid.

Source positions are exact float32 bytes decoded by established readers.
Rigid fits use host-double vector algebra and a declared0.001 absolute corner
tolerance; they are STATIC_INFERENCE geometry relations, not original ELF
transform equations. No source coordinates are manually shifted to raise match
percentages, and no screenshot enters the matching algorithm.

The200550 evaluator uses per-operation float32 rounding, with original
multiply/add order and independently checked comparison instructions. Precision
is FLOAT32_RECONSTRUCTION, not bit-exact EE exceptional/subnormal behavior.
Synthetic camera/planes/radius/range tests cover range equality, strict side
boundaries, direction conditions and missing range descriptor. No synthetic
eligibility result is a current game-frame selection.

Repeated public CLI outputs are byte-identical. Unsupported source tags,
malformed hierarchies, missing original resources, unsupported transforms and
nonfinite values fail explicitly. The optional haybale EOF probe is recorded
NOT_DECODED; it is not a PASS or a silent dependency skip.

## Reproduce

Use the course_delta command in ../README.md, then the regression/pytest
commands. On this host set MASTER_RALLYE_PS2_INPUT and PS2_UI_CORPUS as in the
existing UI tests. Set TEMP/TMP to an ignored writable directory; the existing
hardlink test may require a permitted host run under Windows sandbox.
Pytest can be supplied from the ignored phase dependency directory via
PYTHONPATH. No network or Ghidra is needed for the survey itself.

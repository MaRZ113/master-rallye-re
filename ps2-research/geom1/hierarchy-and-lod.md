# Hierarchy, source alternatives and visibility

All decoded mesh/strip and PC draw records participate. Ancestor tags/path/offsets,
node counts, flags and compiled paths remain available. Container/LOD semantics
are not assigned from tag/name counts. AUTHORED_VISUAL_GEOMETRY is never reported
as SIMULTANEOUSLY_VISIBLE_GEOMETRY. Named vehicle alternatives retain REFL1 limits.

Repeated triangles can match the same opposite face. Consequently France has
41620 PS2 exact matches but60198 PC exact matches; this is meaningful directional
source coverage, not equal budgets or extra visible terrain. PC-only candidates
may be LOD/helper/alternative partitions. Unmatched PS2 foliage does not establish
more tree instances. Raw strip order/parity, ADC suppression and flags are kept;
runtime culling, backface, draw order and active LOD remain UNKNOWN.

# Chrome and trim: bounded classification

Kia root.20 is a real visual tag2 mesh with28 diagnostic source faces. Its
primary mlamp32-tga and authored secondary chrome-tga are associated with
`$shader(carshiny)`. The original3ade58 handler overwrites the latter with the
same render target as painted body meshes. There is no independent chrome mode
proved by this selected material.

This is a useful negative result: CHROME-TGA.GXI exists and is referenced in
source, but its pixels are not thereby bound to the selected final second draw.
The selected path shares selector1, local-normal grayscale preparation and the
mode3 additive contract. Whether another vehicle's chrome-like surface uses
another shader remains outside this bounded study.

REAR128-TGA is retained as a resource/material name lead, not designated a rear
view camera or dynamic reflection source. The rubber exception retains a different
static image while still using mode3/normal coordinates. That exception concerns
texture choice, not an opaque nonreflective material category.

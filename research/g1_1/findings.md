## Core writer

`CourseRaceLogicAuthoring.set_marker_position(list_name, index, runtime_xyz)`
binds a named source list and source ordinal to exactly one direct
`Marker Pos` `Vector3/@Value`. It refuses absent/duplicate/ambiguous list
structures, missing or malformed positions, invalid indices, and non-finite
values. It serializes only the selected source attribute and checks an XML tree
projection that preserves all other values, names, attributes, ordering,
unknown fields, and marker topology. `Marker Dir` has no setter.

The edit manifest schema is `master-rallye-race-logic-edit-v2`. Route and limit
changes use the semantic roles `race.route.raceline.marker_position` and
`race.limit.{left|right}_{inner|outer}.marker_position`. Entries contain the
list name, zero-based marker index, old/new XYZ, and delta. The report records
the unchanged source marker count and order for each present supported list.
No-op XML remains byte-identical.

Warnings are advisory and do not reshape the data. They identify near-zero or
large gaps, extreme adjacent spacing ratios, severe source-order backtracking,
and obvious side/inner-outer inversions against the course's own unchanged
RaceLine. No fixed 20-unit spacing rule is enforced.

## Blender workflow

RaceLine and the four limit lists keep their individual source-indexed marker
helpers and literal source-order polyline. Moving an editable point refreshes
its diagnostic polyline. The panel displays list/index, approximate RaceLine
source-order progress, adjacent gaps, and the list's evidence status. Marker
rotation is locked as a read-only `Marker Dir` preview; scale has no source
meaning. Export uses each helper's evaluated world position and the shared
Blender/source coordinate conversion.

Cameras and their optional direction rays remain diagnostics. RaceLine and
limit polylines and all direction rays are editor-only; semantic marker point
helpers are the only G1 objects traversed for export. The exporter requires an
exact helper inventory matching the XML list and validates the captured source
hash, list ordinal, list path, count, and marker identity before applying
positions. Missing, duplicated, stale, or read-only helpers are refused.

The stable Race Logic writer now accepts G0/G0.1 fields plus these five
Marker-Pos-only lists. It does not accept Marker Dir, Cameras, marker topology,
DX/GXM, tag100, tag1400, physical data, or arbitrary XML paths.

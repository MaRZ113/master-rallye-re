## Evidence boundary

- `StartArea`: runtime edits confirm that its four ordered marker positions define the physical starting-grid frame; exact slot interpolation is unknown.
- `FinishArea`: runtime edits confirm that its marker geometry affects the race-completion region; it is not claimed to be the sole finish subsystem.
- `RaceLine` Progress/LastMarker/Rank has executable support; the local RaceLine Pos edit caused a visible progress-indicator disturbance where the samples were encountered. No obvious AI steering change was observed in that probe; this does not show RaceLine is unused by AI globally. Limit classification remains executable-supported; the first LeftInnerLimit runtime edit is `INCONCLUSIVE_RUNTIME_PROBE`. Cameras XML MarkerList linkage remains unknown.
- The separate LeftOuterLimit 58–60 candidate is prepared and awaiting a human runtime test. Probe outputs default to the absolute runtime-root `D:\Game\Master Rallye\research-output`; tracked corpus reports stay under repository `research/`. `--output-root` selects another explicit destination.
- `FinishAreaQuick` is one additional literal list name observed in the principal corpus. Its name is not treated as semantic proof.
- Marker direction and other source fields remain preserved. This inventory adds no writer support to the listed future families.

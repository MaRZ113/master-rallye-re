## Observed grammar

The samples share the bounded common vertex/normal/color/UV/local-index prefix.
After it, the reader accepts a counted flat draw stream. Each supported
record has a tag-2 20-byte geometry core followed by an 11-byte raw render
prefix, a bounded count of length-prefixed texture strings, and a zero
terminal. A counted global index table follows the records and precedes the
classified trailing/collision data.

The common geometry fields supply vertex base, local vertex maximum, index
start, and index count. The opaque legacy prefix is stored verbatim. Its
render/material field semantics remain unknown; the parser does not reinterpret
it using revision-135 offsets. No legacy writer is available.

## Import decision

All nine samples reconstruct an exact stored-global index sequence, with
valid table counts, draw ranges, and complete disjoint draw coverage. They
receive structural import validation. This is sufficient for a Blender mesh
preview, not for retail authoring or runtime compatibility claims.

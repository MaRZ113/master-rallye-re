## Observed grammar

The common geometry prefix is followed by a counted flat tag-2 draw stream.
Each record has the shared 20-byte geometry core, an 11-byte raw render
prefix, length-delimited texture strings, and a zero terminal. A global index
table follows the records. The bounded revision-specific reader validates
both table envelopes and retains the raw render prefix without claiming its
material semantics.

## Import decision

All 26 samples reconstruct their stored global indices exactly and pass the
current structural checks. The Blender importer can display these resources
with conservative texture preview. The result does not establish revision-131
runtime parity or writer support; all existing authoring writers remain
strictly gated to exact revision-135 inputs.

# Speed Matrix

The menu label has a concrete file operation: local Flow Builder ID 9 opens Load SpeedFunction filtered to SF Files (*.sf) and stores the selected .sf state in the editor. ID 8 clears the state and UI widgets. No direct disk writer appears in those handlers.

The UI labels show eleven columns, Delta and Status. Build modes consume the selected state through flow-generation helpers, but the columns' exact semantics and runtime consumers are UNKNOWN. Classify selection as READ_INTO_EDITOR_STATE; classify the separate build modes as WRITE_CAPABLE.

# High-level subsystem map

This map records architectural paths that are supported by executable or corpus evidence. `UNKNOWN` means the requested subsystem could not be mapped to a behavior-backed implementation in this reconnaissance. Addresses are build-specific. See `function-map.csv` for proposed names and `function-correspondence.json` for cross-build pair evidence.

# R4D.1 findings and decision

The direct DX loader trace confirms the once-unknown 0x24 dword copies into runtime material +0x34. Its observed bit formula matches all 1,478 source draws. DX flag bytes map in order to runtime +0x22, +0x23, +0x20, +0x21. The first two control alpha enable and blend/test selection. The latter two participate in pass setup, with exact visual effects still unresolved. Byte 3 is zero only for the two no-texture IceCream draw-3 records. See dx-to-runtime-material.md, corpus-hardening.md/json, alpha-path.md, and texture-stage-map.md.

**Glass:** windscreen/glass materials request the alpha blend family and depth writes off; alpha test is not requested by any observed vehicle draw. M2 confirms continuous source-alpha transparency in glass; sorting remains unresolved. **Brake/glow:** byte0=1/byte2=0 bindings still request alpha blend, not alpha test. No additive blend, emission, or dynamic light is proved; M4 confirms alpha response of the active braking layer; the base lamp remains. **Body/paint/decal:** stage 0 modulates texture with vertex diffuse. Slot 1 sets env capability, and the env shader uses camera-space normals and a second stage. Whitepaint/chrome helper appearance and decal-specific behavior are confirmed by M1/M3 as reflection helpers, gated by Reflections. **Damage env controls:** RemoveEnvMap and EnvMapFadeStrength registration is known, but per-material attenuation remains untraced.

Legacy texFinder heuristics at this checkpoint: glass **PARTIALLY_SUPPORTED**; chrome **PARTIALLY_SUPPORTED**; paint **PARTIALLY_SUPPORTED**; decal_on_base **STILL_UNVERIFIED**; glow **PARTIALLY_SUPPORTED**; light **STILL_UNVERIFIED**. Texture names alone do not prove render mode.

Blender Preview V2 now uses the traced alpha flags, while ordered slots, raw flags, and mask remain metadata. It does not compose the unverified secondary stage or export materials. M1-M4 have human in-game results recorded in runtime-results.md/json. The material-to-stage resource binding for Null-slot cases, visual helper effects, damage attenuation, and transparent sorting remain open. The runtime closeout supports a conservative R4E same-topology material and texture authoring phase. No R4E work is part of this commit.

## Regression evidence

67 synthetic tests passed. Blender 5.2.2 synthetic import/save/reload/positions-only export passed, with Preview V2 slot/flag/mask metadata assertions. The diverse real Blender suite passed on 22 resources with 14 byte-identical zero-edit exports. Full corpus checks passed: 78/78 DX zero edits and one-position edits, 28/28 tag-101 collision zero edits (27/27 finite translations; Forklift static-only), and 6,960/6,960 DXT byte-identical round trips. Generated reports and game-derived candidates remain ignored. No source DX bytes were modified.

# R5V-I.0 unlock policy

ID27's availability predicate reuses native physical ID10 as its comparison
oracle, so its diagnostic slot follows the existing
`Progress/UnlockedCars/T2CupCar1` gate and stock cheat overrides. It does not
modify T2 class reachability, save data, PlayerState, or the native ID10
record. The appended `T2_Car8` UI widget retains the corresponding stock
locked art and button-disabled control.

Runtime test with T2 already available through legitimate progression. Do
not bypass class unlocks or edit a save. Verify locked and unlocked states
only if the test profile naturally supports both; a locked slot must not be
treated as proof of ID27 physical selection. Availability is independent of
the sparse physical mapping and remains runtime-pending for this candidate.

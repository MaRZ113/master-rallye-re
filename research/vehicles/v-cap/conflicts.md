# Capacity ownership and conflict boundaries

No working DLL/EXE was changed. These are integration constraints for a future
isolated runtime, not findings that the currently accepted SDK33 is broken.

| Owner / range | Relationship | Required action |
|---|---|---|
| Registry allocator/lifetime and RaceTest references | Intentional supersession of exact SDK33 operands | Apply parent then one complete configured layer before first construction. Require singleton6F5ED4==0; refuse late injection. |
| `458D3F` initializer call | New helper chains the supplied SDK33 initializer exactly once | Retain original private prefix and ABI; do not overwrite the hook with an unrelated staged initializer. |
| `481E20/481E50` physical/class maps | Capacity core becomes the sole complete map owner | Preserve every existing SDK33 ID/class/relative position. Other mods must query the descriptor, not install another mapping hook later. |
| `4819A4` position publisher | Bound changes from13 to max configured class count | Requires matching scene widget/frame generation; it is not sufficient to widen just the comparison. |
| Parent private allocation at10000000 | Code/data prefix and its RW page remain owned by prior helpers | Reserve the computed allocation before resume, keep old writable ranges, protect new code/tables RX. Fail on an occupied region; do not silently choose another base for absolute parent references. |
| Existing SDK launcher | Its sealed schema admits named older profiles and fixed allocation cases | Add a distinct reviewed manifest/descriptor path. Current V-CAP artifacts deliberately are not accepted launcher packages. |
| Extra Options SDK binding | May recognize exact accepted parent hook composition | Rebind against the final combined capacity operations; never install its older SDK33 patch layer after the capacity core. Its256 per-car states need their own count-aware adapter. |
| Extra Options tire/skin state | Physical identity and family lookup are separate from model variant/livery | Preserve INI keys and values, retain2 player dimensions; do not widen race participants with registry size. Family32-byte cache is a separate source guard. |
| Renderer optional bridge45583201 | Family/participant queries; no registry-sized array in this bridge | Preserve standalone operation and existing shader/material fallbacks. New query ABI can be additive. Do not claim installed DLL compatibility from source review alone. |
| Original network selectedCar | Byte field shared by both peers;255 also overlaps inactive -1 representation | Negotiate a wider protocol/catalog or block unsupported network IDs. No local-only integer widening fixes the peer wire format. |
| Saved physical IDs/class snapshots | Resource identity outlives livery textures and menu order | Preserve reservations/tombstones; compare catalog identity, not texture SHA. Do not migrate active championships or silently rewrite saves. |
| Future fourth class | Three frontend ordinal/count cells overlap following object fields | Separate state relocation, campaign schema, AI/navigation/localization changes. Do not treat a catalog T4 as native support. |

CPU experiments prove emitted core behavior only. They do not resolve collisions
with unknown third-party hooks, omitted indirect consumers, frame-bank native
loader limits, GPU rendering, or the complete game lifecycle.

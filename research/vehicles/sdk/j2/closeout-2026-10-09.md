## Root cause and correction

The ID27 arm of `FUN_00481E50` set class T2 but stored local ordinal 7 at
`this+0x14`, the T1 ordinal field. The corrected mapper instruction is
`C7 46 18 07`, storing local7 at T2's field. The native layout invariant for
all generated sparse reverse mappers is:

```text
local_field_offset = 0x14 + 4 * class_id
```

For ID27/class 1 this selects `this+0x18`. The constructor publication stub
retains the separately verified stack-ABI correction. ID26/class 0 continues
to use `this+0x14`; the stock ID7/T2-local0 path and stock mapper fallback are
unchanged.

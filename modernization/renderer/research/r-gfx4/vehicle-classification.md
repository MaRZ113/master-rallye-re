# D3D-only vehicle constellation classifier

The classifier itself uses only intercepted D3D state and observed resource generations. No Broker, entity pointer, asset name, EXE structure read, texture filename or fixed draw number participates. Exact pristine SHA and shared indexed return VA 0x0057707E / RVA 0x0017707E are required. Enclosing shared draw owner VA 0x00576970 / RVA 0x00176970; actual COM call VA 0x00577078 / RVA 0x00177078. Addresses are CONFIRMED_BY_EXISTING_RESEARCH; vehicle semantics are the new runtime-supported structural inference.

Group WORLD matrices must be finite rigid affine transforms. Existing mutual unique nearest temporal matching uses immutable generation/material/draw signatures, distance² <=100 and basis difference² <=2. A chassis needs age >=4 and >=2 motion observations (translation² >.0025 or basis change² >.0001). Stopped previously dynamic tracks retain their evidence. Multiple body draws/at least two signatures use FVF 142/152/242/252, with at least one opaque stock-env 152 draw; not every body draw needs env mapping.

Wheel candidates have >=2 draws, all FVF 112 + stock env + opaque/depth-write. Triangle count 252 and exact draw count 4/5 are observations only. Wheels need valid, unambiguous transform/resource evidence; independent motion/age is not required. Wheel orientation/spin may make a track cold while the centers still establish the rectangle.

Wheel centers use inverse chassis rigid basis: local[a] = dot(wheel.translation - chassis.translation, chassis.row[a]). Bounds are |X| .35–2.5, |Z| .5–4, Y -2–1.5. A rectangle has one point per X/Z sign quadrant. Bilateral X error and front/rear width error <= .15+.15*mean|X|; axle Z error <= .15+.15*mean|Z|; longitudinal center offset <= .2+.2*mean|Z|; Y spread <=.5. These deliberately broad bounds accept all supplied model patterns without embedding them. Z signs are structural regions; authored front/rear naming is not recovered.

At most 8 nearby wheel candidates per chassis, 128 transform groups, 64 signatures/group. Enumerate four-wheel subsets; exactly one accepted rectangle required. Multiple plausible rectangles, >8 candidates, shared wheel between chassis, ambiguous temporal tracks or capacity overflow fail closed. A wheel cannot belong to two constellations. Global conflicts are rejected simultaneously; draw traversal cannot select a winner. This supports multiple instances sharing the same geometry; there is no max-four-car limit. Synthetic two-car and varied dimensions/rotation/permutation/cold-wheel tests pass. 5+ cars are untested in this graphics line.

Accepted chassis track ID is the device-local constellation ID (monotonic across Reset). Body and wheel groups have separate object identities, same constellation ID and seven explicit reasons: dynamic_chassis, body_draw_cluster, wheel_signature, four_wheel_match, bilateral_symmetry, axle_pairing, unambiguous_assignment. Symmetry error is a diagnostic sum, not a probabilistic confidence. Only all seven give STRONG_FOUR_WHEEL. Three-wheel candidates never become strong positives.

**Draw-time lifetime:** current-frame full geometry becomes known only at Present. Reflection uses the immediately previous complete frame's strong constellation and a unique current WORLD/signature match; it does not retroactively modify/replay draws. Exact per-draw signature must belong to that previous resource generation. This one-frame lease can cover a newly occluded wheel; missing/incomplete evidence at the next Present drops the identity. No cold three-wheel scene can authorize an override. F10 separates object_class_at_draw/constellation_id_at_draw from object_class_frame_end; object_class on a modified draw is the actual decision identity. Full-frame classifications on Stock captures can appear one frame before visual eligibility.

R-GFX4-2 cleared temporal identities on race/preview projection transitions; that was the normal-frame lifetime bug. R-GFX4-3 clears on successful Reset, relevant pointer recreation, a completed menu-only/missing frame and failed Present. Race-to-HUD/preview within an interval suppresses the current draws without erasing that interval's race history. A newly observed resource pointer generation cannot inherit old confidence. VIEW changes alone, including look-back, do not clear context. Reclassification after camera/LOD visibility loss is conservative; no permanent scene pointer or long-lived cached identity is claimed.

Offline analyze_vehicle_draws.py reports candidate chassis, wheel tracks/local coordinates, symmetry error and accepted/rejected reason. It never joins independently sampled frames or claims the old files contain the new native classifier. See constellation-runtime-evidence.json. Native and offline predicates agree on supplied rectangles; universal scenery rejection and actual CPU cost remain human validation items.

# Logical and effective D3D state

The game maintains its own D3D cache. Never leave native state changed while pretending its logical requested value changed too. Trace.shadow tracks logical state; Trace.effective_shadow tracks actual successful forwarded state. Both update even with Trace.Enabled=false and share a per-device recursive lock. Default-off arguments/HRESULTs/draw forwarding are unchanged and both shadows agree. Unknown observations remain unknown; only initial/reset MAXANISOTROPY1 is used when AF introduces its first native MAX write before a game MAX setter.

Setters update shadows only on success. AF extra MAX affects only effective state. FOV keeps original requested matrix in logical and native copied matrix in effective. Successful GetTextureStageState/GetTransform first call the real device; if a known overridden value differs, the game receives the logical value. Native/effective output is separately captured. A failed getter retains its HRESULT/output; no PUREDEVICE failure is fabricated into success (tested retail flags0x54 include PUREDEVICE, so some getters may fail natively).

Successful Reset invalidates both state shadows and resource observations; config/caps survive. No old state is blindly replayed after Reset. Next relevant game setters re-establish AF/FOV. Failed Reset preserves known states. Shadow Off is a classification decision with no Set* mutation.

Unreviewed Begin/Apply/Capture/CreateStateBlock and projection MultiplyTransform enter conservative per-device Stock fallback. Restore each known overridden stage0 value and projection through native setters before the operation; update only effective tracking, log fallback, then permanently disable visuals for that device. Other features cannot leak through an unknown native state block. Failed restoration returns the real failed setter HRESULT and does not pretend restoration succeeded or proceed with the unreviewed operation. Default-off blocks retain original forwarding. These active-feature fallback paths have mock coverage; game use remains unobserved.

Trace schema1 is additive. Legacy draw.state is explicitly state_semantics=logical. effective_state.inherits_logical=true overlays stage0 keys16/17/18/21 and projection; all other values inherit logical because no feature changes them. Null is unknown, not a default. Each event exposes effective_arguments, effective_payload_bits and feature_mask:1 AF,2 FOV,4 shadow-off. Draw masks also reflect active state differences. forwarded=false identifies suppression. native_override/native_only=true represents additional native calls rather than game-requested setters; failed probes are recorded and do not advance either state. Projection events decode original/effective/configured VFOV and original aspect. Session config and per-device caps record requested/effective flags and reasons.

F10 retains8192 draw/16384 event bounds, native FrameBuffer<=32MiB (compile-time assertion),64MiB output and marked truncation. Compact effective overlays avoid doubling snapshot storage. summaries.counts remain counts of game wrapper calls; native-only extras are distinct capture events. R-GFX2 tools can still read schema1; summarize_visual_trace reconstructs effective state from overlays and cannot declare a human visual PASS.

Final closeout: MAG is never rewritten; its logical/effective values coincide. Reset re-establishes only eligible MIN filtering and source90 projection when the game next sets them. Existing matrix/event payloads permit source-family decoding offline without additional high-volume trace records.

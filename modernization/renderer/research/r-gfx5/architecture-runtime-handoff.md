# R-GFX5-6 — ручной ретест HUD и true Exclusive

**READY_FOR_HUMAN_RUNTIME.** Агент собрал и проверил кандидат, но не устанавливал DLL и не запускал игру. Кандидат: `modernization/renderer/.build-msvc/Release/d3d8.dll`; проверенный хеш и размер — [build.json](../../data/build.json). Сохраните текущие рабочие DLL/INI для отката и установите кандидат обычным способом. EXE/ассеты не меняются. После каждого изменения INI перезапускайте процесс: нельзя смешивать старый процесс с новой архитектурой.

Все селекторы остаются числовыми с прежним смыслом: Display.Mode0Stock/1Windowed/2Borderless/3ExclusiveFullscreen; InterfaceMode0Stock/1Centered4x3/2PreserveMargins; AA.Mode0Stock/1MSAA; booleans0/1. [Пример](../../MRRRenderer.ini.example) и [stock-plus](stock-plus.ini) сохраняют вертикальные комментарии и совместимость строковых значений. Для проверок явно переключайте указанные поля; остальную принятую конфигурацию AF16/FOV/отражений/freeze держите постоянной.

Если fullscreen-размер/refresh действительно отсутствует в enumeration, ожидается явный `*_validation_rejected`, D3DERR_NOTAVAILABLE и конкретная причина, без native call или mode alias. Это не PASS запуска поддерживаемого режима. Не используйте1734×480 как Exclusive тест. Refresh0 сохраняет native default; actual refresh и способность конкретного драйвера к возврату из Alt+Tab остаются runtime-фактами.

F10 сохраняйте в каждом важном состоянии: `P1-hud`, `P2-menu`, `P3-extreme`, `P4-moving/paused/resumed`, `D4-exclusive`, `D5-exclusive-msaa`, `D6-restored`, `combined`. Сохраняйте session вместе с frame; producer должен быть **R-GFX5-6**, DLL-хеш совпадать с build.json. Для нового полного bounded бюджета перезапустите игру: packet/render-local диагностика ограничена3кадрами/64идентичностями/256записями на устройство.

Для HUD проверяем `ui_margins.architecture=render_local_world_v2`, `persistent_packet_writes=0`, restore boundary`immediate_native_draw_return`. `ui_packet_lifetime` содержит текущий engine XY, anchor/current rule и desired effective X; `shifted=false` означает отсутствие memory edit, а не отсутствие native эффекта. Фактическое применение видно в `ui_render_local` и draw feature_mask128: native WORLD X → temporary X → original matrix. В frame полные native-only SetTransform payloads должны восстановить исходные16bits-значений; `effective_state.world_translation_x` отражает X во время draw. Ожидается restore_failures0/restore_pendingfalse; другие3D/UI draws не наследуют временный WORLD. Center/unknown остаются без сдвига. Retained-without-rule-match может расти при обычной анимации и не является визуальным PASS.

Для display сравниваем bounded `display_native_attempt`: requested/sent/returned, mode, AA reason, HRESULT, последовательность Create/Reset; validation rejection не native attempt. В Exclusive sent/returned.windowed=0, dimensions совпадают с exclusive_target, `window_commit_status=exclusive_native_owned`; нет proxy window commit. `display_cooperative_transition` покажет смену native cooperative HRESULT; reset_policy — реальные вызовы/результаты, без внутреннего бесконечного retry. ИсходныеHRESULT сохраняются.

The selected override is downstream of the engine cache, inside the proxy's actual native DrawPrimitive forwarding. It requires PreserveMargins, live verified UI projection, the final packet consumer context, the exact draw return RVA, triangle-list primitive, FVF0x142 and identity effective VIEW. Whole-owner fingerprint validation, fixed retail placement and the existing feature-local compatibility gate still control hook installation; unknown/malformed owners remain Stock. No new whole-EXE hash profile is required.

For each eligible draw, GetTransform(WORLD) reads the actual native matrix. The proxy copies its16floats locally, adds `direction * half_extra` only to `_41`, sets the temporary matrix, forwards the draw exactly once, and immediately restores every original matrix bit before returning. Logical trace state, game packet bytes and cached transform storage receive **zero coordinate writes**. A repeated draw starts from the restored native matrix, so it cannot accumulate a second offset. Current animation remains dynamic; no learned X is frozen. Nonfinite/projective matrices, unknown anchors and failed native reads stay unmodified.

The original draw HRESULT survives the restoration step. Restoration failure disables the UI margin feature, retains an explicit pending original WORLD, and prevents subsequent draws from forwarding until repair succeeds. Successful native Reset clears pending state; failed Reset does not. Get/temporary-set/restore failures have separate counters. Present is now an anchor-clock/diagnostic boundary, not a coordinate restore boundary. The native return bridge preserves registers, flags, x87 and SSE; synthetic RET4 and actual RET0Ch cleanup contracts pass. Consumer stacks are bounded16deep and overflow disables the feature.

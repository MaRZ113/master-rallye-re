On replay pause, the same exact-build, render-thread, device, scene, UI-consumer, FVF, topology, typed pause, replay, owner, and complete-identity gates authorize hiding every verified draw in that native UI packet stream. This includes both previously learned race-HUD packets and new packets introduced by the replay pause window. A complete identity is enough for this narrowly certified paused-replay UI stream; incomplete or stale draws remain visible. The ordinary non-replay pause menu, frontend, results, loading, and uncertain contexts remain fail-open.

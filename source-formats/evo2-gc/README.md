# 4x4 Evolution 2 (GameCube, GE4E7D) — exclusives vs PC

`tools/rvz.py`: minimal Dolphin RVZ reader (zstd groups, RVZ packing; junk regions
returned as zeros) + GameCube FST extraction; needs Python 3.14+ (`compression.zstd`).
The disc has 27 files; `TRUCK.pod` uses the same POD2/SMF/TIFF formats as the PC game
(readers in `../decoders/evo2_formats.py`).

## Roster difference (`tools/compare_trucks.py`)

PC `TRUCK.POD`: 150 TRK, 1126 members. GC `TRUCK.pod`: 152 TRK, 1242 members.

| GC-only TRK | truckName (as stored) | Model / textures | Class |
|---|---|---|---|
| `CFRT.TRK` | Calmini Nissan Frontier Race Truck (2001) | `CALMINI.SMF` (+ `CALMINI0` LOD), `CALMINI*.TIF` | Race Truck |
| `JWR.TRK` | Jeep Wrangler Rubicon | `JEEPWRGR.SMF` (+ LOD), `WRGRTIRE*` tyres | Compact SUV |
| `SMT.TRK` | "Vauxhall Frontera" (model field: Stillen Silverado Monster Truck) | `STILLEN.SMF` (+ LOD) | Race Truck |
| `WDRT.TRK` | Warn Dodge Dakota Race Truck | `WARN.SMF` (+ LOD) | Race Truck |

Also GC-only: the `31X10..44X15 MUD` tyre family (36 SMF + TIF). PC-only: two duplicate
Dodge Ram 1500 Regular Cab TRK variants (`DR1RS42/43`). `SMT.TRK` carries a stale
truckName; the geometry is the Stillen Silverado monster truck, not a Frontera.
`GCMODEL.POD` (track/world SMB models) and `PS2BIG.POD` (track textures) are not vehicles.

`tools/smf_export.py` exports any SMF to OBJ/MTL/PNG; previews are private in
`.research-output/evo2-gc/`.

## Suspension is procedural (PC and GC, 2026-11-13)

Owner: suspension parts are missing on imported Evo 2 trucks (PC and GC). Cause: the SMF models
contain no shocks, springs or links. The only suspension meshes are the solid-axle beams
`AxleR` (rear, ~50 trucks) and `AxleF` (front, ~8), which the game draws in a separate moving
pass (our adapters hide them as non-static). Everything else is generated by 4x42.exe at runtime
from TRK records:

* `frontSuspType` / `rearSuspType`: 0 = independent, 1 = solid axle (by the axle-mesh pattern).
* `frontSuspSpringType` / `rearSuspSpringType`: 0 / 1 / 2 (2 is common on rear solid axles:
  presumably leaf springs; 0 coil; 1 torsion bar) - semantics NOT TESTED.
* `axleModelName = NULL.BIN`, `shockTextureName = susp.raw`, `barTextureName = NULL.RAW`,
  `axlebarOffset`, per-tyre `spring_arm` (+-5.0), `maxcompr`, `maxangle`.
* `ART/SUSP.RAW` (64x64 8-bit, palette `SUSP.ACT`): four vertical cylinder strips (chrome and
  dark shock bodies, rod, spring) = UV strips for generated cylinders.
* Combos (PC 150 TRK): (0,1,0,2) x83, (0,1,1,2) x25, (0,0,0,0) x16, (1,1,0,0) x10,
  (0,1,1,0) x8, (0,1,0,0) x5, (1,1,0,2) x3. GC adds CFRT/WDRT (0,1,0,2), JWR/SMT (1,1,0,0).

4x42.exe (Watcom, image base 0x400000) xrefs: TRK suspension types read at 0x486560..0x4865B2,
`spring_arm` at 0x486ACD; `axleModelName` / `shockTextureName` / `barTextureName` /
`axlebarOffset` at 0x5F0001..0x5F0094 (one loader). Next: follow the loaded fields to the
renderer that builds the shock/spring/bar geometry, then reproduce it as static MR geometry
(or a runtime-animated add-on) for both PC and GC trucks.

# Universal MR Classic authoring

Changed: MR Classic is a donor-neutral mode on the editable scene, using explicitly selected mesh/face roles and native MR material references. Original source geometry/livery is the starting point; derived geometry and material changes are intentional. The source renderer may remain unqualified without prohibiting deliberate MR restyling. Strict Source Fidelity is not relabelled as PASS.

`authored_profile` emits a regular common-bridge profile for the evaluated project. Explicit face-material assignments split mixed groups; reflections cover their complete derived group and preserve diffuse. No rectangular source-atlas reflection classifier is used. Glass cannot silently include opaque-body roles. Wheels keep their separate nodes and transforms. Scale is explicit user authoring, not an assumption that source units are metres.

Legacy `classic_pipeline`, `classic_style` and GT recipes/defaults remain unchanged. The compatibility snapshot reads an existing GT-derived native family into a private UVS with exact native hashes and original local textures; this is not a second GT decoder. Four wheel poses come from its existing explicit preview profile, or the qualified exact frontend correspondence helper; no arch fitting. Unsupported native controller flattening fails. Snapshot output never edits the original GT project.

Practical targets: original Dakar2 Pajero and GT-derived Clio snapshot use the same journal, material authoring, preview cache and native writer. This qualifies common authoring portability, not automatic porting of every Subaru Classic recipe or a gameplay-approved Xbox Pajero. Full donor-neutral style presets and model-specific lamps/glass/controllers remain further work.

# CLASS-T4 pilot — Dakar 2 Xbox vehicles in MR Classic mode

11 November 2026. **PASS OFFLINE / OWNER D3D8 PENDING.** First complete native
imports from Dakar 2 (Xbox), placed in the new T4 class
([NEW_CLASS_RESEARCH.md](NEW_CLASS_RESEARCH.md)).

## Owner policy

Vehicles keep the original game's geometry and diffuse textures; **materials come
from Master Rallye**. This is the MR Classic authoring mode of MASTER_PLAN §3. The
strict Xbox combiner equivalence of DAKAR2_NATIVE_MATERIAL_QUALIFICATION.md remains
BLOCKED and is not claimed: the source shader, secondary stages (T1 mask, T2
environment) and UV1 are replaced by an explicit `mr_classic_material` feature
disposition (new in `scene_semantics.feature_policy`, evidence and impact required).

| Semantic role | MR material (from retail Pajero `car.dx`) |
|---|---|
| paint (body livery atlases) | flags 0x7, secondary `whitepaint-tga` |
| trim (axles, hubs, mudflaps, diff, shocks) | 0x7, `rubber-tga` |
| chrome (wheel faces, exhausts) | 0x7, `chrome-tga`; wheel face alpha test 100 (Xbox GREATER 100) |
| lamp | 0x7, `perspex-tga` |
| glass | alpha blend, `glass-tga` |
| tyre tread | 0x7, `rubber-tga` |
| interior / crew / roll cage | 0x3, no reflection |

Roles are assigned per vehicle by source texture and HIR node name
(`dakar2_classic_pilot.VEHICLES`), never by triangle IDs.

## Geometry

Dakar 2 vehicle draws use cull NONE with mixed winding. MR draws are single-sided
with `(b-a)x(c-a)` along the vertex normals (stock Pajero 2190/2191 triangles).
Each derived triangle is oriented against its own source normals; when the normals
do not decide (|cos| < 0.2) it is emitted on both sides with a negated-normal copy.
Source arrays stay immutable in the copied scene.

| Vehicle | Kept / flipped / two-sided | L x W x H (m) | WB | Track F/R | Wheel r |
|---|---|---|---|---|---|
| Pajero #205 (`PAJERO_HI_0_0.LOD`) | 2341 / 2644 / 9 | 3.981 x 2.054 x 1.802 | 2.613 | 1.710 / 1.752 | 0.397 |
| Nissan Pickup #203 (`NISSAN_HI_0_0.LOD`) | 2120 / 2441 / 0 | 4.632 x 1.969 x 1.573 | 2.936 | 1.673 / 1.673 | 0.395 |

1 source unit = 1 MR metre (authoring choice, as for PC Paris-Dakar Silver). One
common translation centres the axles and puts the mean hub at `Y = -RideHeight`
(0.05, retail Pajero/Navara); hubs are made axle-symmetric (residuals in the pilot
report). Per-slot wheel meshes are kept (`wheel-source0..3`, left side Y-pi oriented).

Native states: windscreen and left/right side panes get MR glass damage (procedural
cracks), rear lamp meshes get MR brake ON/glow; collision is the affine fit of the
donor hull to the structural shell nodes.

## Build and checks

* `tools/create_dakar2_classic_pilot.py --vehicle PAJERO|NISSAN --scene <dakar2-fidelity scene> ...`
* `tools/build_class_t4_pilot.py --base-config <accepted V-DEF4.1 roster-config.json> --pilot <pajero> --pilot <nissan> --game-exe <host>/MRallye.exe ...`
* `tools/make_isolated_game_host.py` makes the launch host (hardlinks, copied configs, no loader wrappers).
* Native D3D9 previewer captures with CW back-face culling show closed bodies, wheels,
  roll cage and spares for both vehicles; UI art is generated by the existing renderer.
* Profile `sdk-multi-addon-roster-experimental-class-t4`, 35 records, native extension 429,904 bytes.

# Glass damage evidence

Native damage combines deformation, vertex color/alpha updates and vehicle
switch-controlled geometry. Coverage alpha differs from reflection weighting.
Changing every alpha value or making windows opaque can hide a source error.

An imported vehicle must preserve meaningful pane ownership before native
intact/broken switching can behave like stock cars. A whole-car glass draw in
one pane case cannot be treated as evidence of independent window damage.

This Studio does not provide a speculative cracked-glass overlay authoring tool.
Native damage remains subject to the phase report and human gameplay checks.

V-SDK4C.1 continues the repaired V-SDK4C Subaru resource with UV-only stock-MR
crack placement. Side UVs repeat the original crack artwork like Navara rather
than stretching one image across a continuous side shell. Four native logical
zones remain; multiple side windows in one zone share a controller. This is an
intentional MR-art adaptation, not GT damaged glass. There is no qualified third
shattered state. Textures, intact panes, lamps and controller records stay intact.

Test front/rear/left/right impacts separately from an undamaged race start, then
race re-entry. Offline original-instruction CPU replay verifies switches and
unchanged deformation; it does not prove the game's collision-to-zone routing.

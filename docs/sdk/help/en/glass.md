# Glass damage evidence

Native damage combines deformation, vertex color/alpha updates and vehicle
switch-controlled geometry. Coverage alpha differs from reflection weighting.
Changing every alpha value or making windows opaque can hide a source error.

An imported vehicle must preserve meaningful pane ownership before native
intact/broken switching can behave like stock cars. A whole-car glass draw in
one pane case cannot be treated as evidence of independent window damage.

This Studio does not provide a speculative cracked-glass overlay authoring tool.
Native damage remains subject to the phase report and human gameplay checks.

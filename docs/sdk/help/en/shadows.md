# Shadow Studio

Qualified addon projects only. Open Shadow Studio from the main toolbar.
Inspect reports the body bounds and original native / selected alpha-support footprints in metres.
Original native removes the per-addon shadow override; Auto Fit uses the existing shadow-only bounds compiler; Custom exposes independent X/Z scale, offsets, margins and support threshold. Reset donor restores the immutable author baseline. Save, Undo, Redo, Restore and Validate use the shared project service.

The support threshold measures the footprint of the original shared texture. It does NOT alter opacity, texture bytes, terrain projection, collision, physics or visual geometry.
D3D9 ground/top-down guides are diagnostic rectangles, not a recreation of the D3D8 terrain shadow. Game testing remains required.

# Classic material pilot

Rebuild as Classic always starts from the immutable source import. The pinned Lancer recipe may select stock-derived tyre mapping and glass independently. The mixed front banner retains its non-environment pass; only optical pixels receive the stock window pattern. Existing source switch groups remain unchanged; Lancer does not acquire unproven cracked-glass controllers.

Classic paint is independent from decal selection. Recipe default follows the pinned profile. Preserve source paint keeps the imported atlas, baked shading, RGB/alpha and environment bindings; it still removes the separately qualified decal overlays. Regenerate qualified fields is the earlier explicitly authored flat-livery mode and may reveal mismatch against neighbouring original atlases. The Lancer material pilot defaults to Preserve source paint after owner feedback. No GT renderer parity is claimed.

Inspect previews and the exact report before approval. Changing the report invalidates Classic build approval. CLI: tools/classic_vehicle.py rebuild --paint-mode preserve_source (with the usual project, recipe, stock-root and output arguments).

# Navigation

Buttons keep text labels alongside original line icons. Workspace selectors expose tabs even when the native tab strip is too narrow. Inspector pages scroll; supported DPI captures use Tk rendering scales, not a claim of mixed-monitor OS DPI qualification.

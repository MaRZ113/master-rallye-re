# Installation

The Master Rallye Randomizer & AI Extender adds configurable AI vehicle
selection and a larger Quick Race opponent menu to the original game.

## Quick Start

1. Confirm that your game uses the supported 32-bit retail `MRallye.exe`.
2. Check whether another mod already provides `dinput8.dll`. Resolve that
   conflict before installing; do not overwrite an unfamiliar proxy.
3. Extract the contents of the mod ZIP into the folder containing
   `MRallye.exe`. Keep the existing graphical `d3d8.dll` untouched.
4. Run `MRallye.exe` normally.
5. Choose the opponent count in Quick Race. The included configuration allows
   up to five AI opponents by default.

The game must be the supported original retail build. The mod checks its
identity at startup and refuses unsupported executables.

## Uninstall

Close the game. Remove only the files installed by this mod:

- `dinput8.dll`
- `MRallyeRandomizerRuntime.dll`
- `MRallyeRandomizer.ini`
- `MRallyeRandomizer.log` and `MRallyeRandomizer-*.bin`, if created

Do not remove or replace `MRallye.exe`, `d3d8.dll`, or other files that were
already in your game folder. If another mod used `dinput8.dll`, restore the
copy you backed up before installation.

endorsed by the game's publisher or developers.

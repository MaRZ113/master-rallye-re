# Master Rallye Vehicle Composer v0.1.0

## Highlights

- Compose a retail carrier, named physics family, and independent model donor.
- Apply persistent vehicle-family binding when the carrier and runtime family differ.
- Inventory packaged `Data.sma` resources and loose overrides.
- Install transactional loose model overlays with hash-checked restore.
- Validate variable-length vehicle configuration schemas.
- Use an interactive CLI or retained automation commands.

## Runtime-verified examples

- Navara carrier / Trooper physics / Trooper model: pass.
- Navara carrier / Trooper physics / Navara model: pass.
- Navara carrier / Navara physics / forklift model: race loads; Navara physics remains active.

The current forklift package showed no collision or damage behavior because it
has no usable collision hull.

## Compatibility and limitations

Only the retail executable with SHA-256
`bf8aef32407eb6552c05045b8abef149f32983cedd9503b865069b444c5f96b4` is
supported. Other executable builds and arbitrary model/physics pairings have
not been verified. Asset-specific geometry, wheel placement, textures,
collision, damage, and resource dependencies can vary.

`tools/physics_bind.py` remains available as a backward-compatible entrypoint.
